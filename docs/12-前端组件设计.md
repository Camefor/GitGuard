# 桌面组件设计（Avalonia，P3 阶段）

> **交付阶段**：同 `11-前端UI设计.md`，v0.3 启动桌面端时才落地。MVP 阶段仅保留骨架。

## 1. 组件分层

| 层级 | 职责 | 可依赖 | 典型组件 |
| --- | --- | --- | --- |
| 原子 | 无业务含义的最小单位 | 无 | `SeverityBadge`、`PillButton`、`CodeBlock` |
| 复合 | 组合原子解决具体 UI 模式 | 原子 | `FindingRow`、`AllowlistForm`、`HookStatusCard` |
| 业务 | 承载业务语义，绑定 ViewModel | 原子 + 复合 | `RepositoriesView`（`GGD-0042` 已落地）、`RepoDetailView`、`ScanHistoryView`、`AllowlistEditorView` |
| 页面/路由 | 导航入口，编排用例 | 业务 + 布局 | `MainWindow`（导航壳）、`SettingsPage` |

## 2. 组件命名与目录结构

```text
src/GitGuard.Desktop/
├─ Program.cs                  # 进程入口（Avalonia AppBuilder）
├─ App.axaml                   # FluentTheme、Light / Dark 主题画刷、全局样式
├─ App.axaml.cs                # 组合根：AppState + GitGuardSession + RepositoryOperations + MainWindow
├─ MainWindow.axaml(.cs)       # 侧边导航壳 + 内容区
├─ AppState.cs                 # 应用级状态（语言 / 版本）
├─ Localization/
│  ├─ DesktopLanguage.cs
│  ├─ DesktopSection.cs
│  └─ DesktopText.cs           # 中 / 英文案表（枚举键 + switch）
├─ ViewModels/
│  ├─ MainViewModel.cs
│  ├─ NavigationItemViewModel.cs
│  ├─ SectionViewModel.cs
│  ├─ RepositoriesViewModel.cs      # 仓库页：登记 / 列表 / 详情 / 扫描 / 移除
│  ├─ RepositoryItemViewModel.cs    # 仓库列表项 + 目录缺失徽标
│  ├─ HookStatusRowViewModel.cs     # Hook 状态行
│  ├─ ScanHistoryViewModel.cs       # 扫描历史：分页时间线 / 运行明细 / 编辑器跳转
│  ├─ ScanRunItemViewModel.cs       # 时间线运行项
│  └─ FindingItemViewModel.cs       # 脱敏发现项（片段 / 指纹）
├─ Views/
│  ├─ RepositoriesView.axaml(.cs)   # 仓库页左右分栏视图
│  └─ ScanHistoryView.axaml(.cs)    # 扫描历史三栏视图
├─ Services/
│  ├─ IRepositoryOperations.cs      # 仓库页数据访问契约 + RepositoryDetail
│  ├─ RepositoryOperations.cs       # GitGuardSession 适配器（Task.Run 隔离 UI 线程）
│  ├─ IEditorLauncher.cs            # 外部编辑器启动契约 + 结果状态
│  └─ ShellEditorLauncher.cs        # 环境变量 / 系统文件关联启动实现
├─ Controls/                   # 规划：原子 + 复合控件
└─ Resources/                  # 规划：图标等静态资源
```

> **实现说明（`GGD-0041` / `GGD-0042` / `GGD-0043`）**：`GGD-0041` 落地骨架文件；`GGD-0042` 创建 `Views/RepositoriesView`、`Services/IRepositoryOperations` 与 `RepositoryOperations`，并补齐仓库页三个 ViewModel；`GGD-0043` 新增 `Views/ScanHistoryView`、扫描历史三个 ViewModel、`IEditorLauncher` / `ShellEditorLauncher`，并在 `IRepositoryOperations` 扩展分页历史与运行明细查询；`Controls` / `Resources` 仍为规划目录。界面文案由 `Localization/DesktopText.cs` 集中维护，取代原计划的 `Resources/zh-CN.axaml` / `en-US.axaml`——避免资源字典重载与反射，语言切换只刷新绑定属性。

**命名**：

- View（`*View.axaml`）：仅承担 UI 渲染；逻辑进 ViewModel。
- ViewModel：`CommunityToolkit.Mvvm` 风格的 `ObservableObject` + `RelayCommand`。
- Controls（原子/复合）：无 ViewModel，纯 Props；通过 `StyledProperty` 暴露。

## 3. 组件契约

### 3.1 `SeverityBadge`

- **Props**：

| 名称 | 类型 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- | --- |
| `Severity` | `Severity` | 是 | - | Critical/High/Medium/Low |
| `Compact` | `bool` | 否 | false | 紧凑模式 |

### 3.2 `FindingRow`

- **Props**：`Finding`（领域模型）
- **Events**：
  - `OpenInEditor`（载荷 `{ FilePath, LineNumber }`）：请求外部编辑器打开。
  - `AddToAllowlist`（载荷 `Fingerprint`）：触发白名单对话框。
- **Slots**：无

### 3.3 `AllowlistForm`

- **Props**：`AllowlistDraft`（可空，表示新建）
- **Events**：`Submit`（载荷 `AllowlistDraft`）、`Cancel`
- **校验**：三条件至少一个；Reason ≥ 5 字符；校验失败时阻止 `Submit` 事件外发。

### 3.4 `RepositoriesView`（GGD-0042）

- **数据源**：`RepositoriesViewModel`（构造注入 `IRepositoryOperations` 与初始语言）。
- **布局**：左栏 340px（登记路径输入、登记 / 刷新按钮、已登记仓库列表与空状态），右栏为仓库详情（名称 / 路径 / 目录缺失提示、GitGuard 与 Git 版本、Hooks 目录、Hook 状态行、最近扫描摘要、扫描 / 移除操作与二次确认条）。
- **服务契约**：`IRepositoryOperations` 暴露 `ListAsync` / `RegisterAsync` / `RemoveAsync` / `LoadDetailAsync` / `ScanAsync`，实现类 `RepositoryOperations` 负责创建 `GitGuardSession` 子会话并以 `Task.Run` 把 SQLite / Git 访问移出 UI 线程。ViewModel 测试以假对象驱动，不启动 Avalonia。
- **状态**：`IsBusy`（列表级操作）、`IsDetailLoading`、`IsScanning`、`IsRemoveConfirmationVisible`、`IsEmpty`、`IsSelectPromptVisible`、`CanInteract`；详情请求以递增版本号丢弃过期响应。
- **错误**：`RepositoryException` 按 `ErrorCode` 映射中 / 英提示；其他异常直接展示消息。消息分为列表级（`ListMessage`）与详情级（`DetailMessage`），不弹模态框。
- **本地化**：`Relocalize` 刷新页面标签、列表项缺失徽标、Hook 状态行与最近扫描摘要；缓存的仓库页在全局语言切换时同样刷新。

### 3.5 `ScanHistoryView`（GGD-0043）

- **数据源**：`ScanHistoryViewModel`（构造注入 `IRepositoryOperations`、`IEditorLauncher`、返回回调与初始语言），由 `RepositoriesViewModel.History` 持有并以覆盖层呈现。
- **布局**：三栏 300 / 330 / 自适应——扫描时间线（每页 20 条、上一页 / 下一页与页码）、发现项列表（规则 ID / 位置 / 严重度 / 提交短 SHA）、发现项详情（规则、严重度、提交、位置、脱敏片段、指纹与「在编辑器中打开」）。
- **服务契约**：`IRepositoryOperations` 新增 `QueryScanHistoryAsync` / `LoadScanRunAsync`；`IEditorLauncher.OpenAsync` 返回 `EditorLaunchStatus`（`Opened` / `RepositoryMissing` / `FileMissing` / `PathOutsideRepository` / `LaunchFailed`），实现类 `ShellEditorLauncher` 解析 `GITGUARD_EDITOR` → `VISUAL` → `EDITOR`，已知编辑器附带行号，否则回退系统文件关联。
- **状态**：`IsLoadingPage` / `IsLoadingRun`、`SelectedRun` / `SelectedFinding`、`IsEmpty` / `IsSelectRunPromptVisible` / `IsNoFindingsVisible` / `IsSelectFindingPromptVisible`、`CanGoPrevious` / `CanGoNext` / `CanOpenInEditor`；页面与运行请求各持递增版本号，快速切换时丢弃过期响应。
- **脱敏边界**：`FindingItemViewModel` 只暴露 `SnippetMasked` 与 `Fingerprint.Hex`，不持有原文；编辑器失败仅显示本地化原因，不展示进程原始输出。
- **本地化**：`Relocalize` 刷新页面标签、分页文案、运行项结果 / 扫描类型 / 计数与发现项严重度。

## 4. 状态管理

- **本地状态**：UI 临时态（如展开/折叠）保留在 View（`StyledProperty`）或 ViewModel。
- **跨组件状态**：通过 ViewModel 组合 + 依赖注入；共享状态保持单向数据流（上层 ViewModel 持有，下级通过 Props 读取）。
- **全局状态**：
  - `AppState`（应用级：当前语言、版本）由 `App.axaml.cs` 组合根创建，并在进程内保持单例后注入 `MainViewModel`；`GGD-0042` 同时把 `GitGuardSession` 包装为 `RepositoryOperations` 注入仓库页，当前尚未引入 DI 容器。主题与 CLI 可执行文件路径配置在 `GGD-0046` 扩展。
  - 不引入 Redux / 事件总线等重量级框架；MVVM + DI 已足够。
- **服务端/异步状态**：MVP 桌面端的「服务端」即本地 CLI 进程；用 `ScanService.ScanAsync()` 返回 `Task<ScanResult>`。

## 5. 组件通信

- **父子**：Props + Events；禁止子组件直接改父组件状态。
- **跨层级**：通过 ViewModel 组合，不使用全局事件总线（避免难以追踪的隐式耦合）。
- **跨 Window**：使用 `IMessenger`（CommunityToolkit.Mvvm 内置），限定 Message 类型清单，不开放匿名 Payload。

## 6. 性能规范

- 列表虚拟化：`VirtualizingStackPanel`（Avalonia 内置），`ItemsRepeater` 优先于 `ListBox`。
- 大量 findings：按仓库 + 时间分段加载；不一次性拉所有。
- 防抖/节流：
  - 筛选输入框 `TextChanged` 节流 200ms。
  - 规则库搜索节流 150ms。
- 禁止在 UI 线程做 SQLite 查询；`RepositoryOperations` 的七个操作均以 `Task.Run` 执行，ViewModel 只 `await` 并更新绑定属性。

## 7. 可测试性

- **ViewModel 单测**：命令触发、属性变更、状态流转全部可单测（无需启动 Avalonia）。`tests/GitGuard.Desktop.Tests` 当前 48 例：`AppState` / `MainViewModel` 的语言切换、导航顺序与页面缓存；`RepositoriesViewModel` 的列表 / 登记 / 扫描 / 移除确认 / 错误映射 / 语言刷新；`ScanHistoryViewModel` 的分页 / 运行与发现项选择 / 脱敏与金丝雀隔离 / 编辑器跳转 / 过期响应；`ShellEditorLauncher` 的缺失与路径逃逸校验；`RepositoryItemViewModel` 与 `HookStatusRowViewModel` 的徽标和 Hook 状态文案。
- **View 快照测试**：使用 Avalonia 的 `HeadlessApplication` + 像素级 Snapshot（仅针对关键页面）。`Avalonia.Headless.XUnit` 11.3 依赖 `xunit.core` 2.4，与仓库的 `xunit.v3` 冲突，暂不引入；`GGD-0041` 以真实启动 + 截图人工核验导航与中英切换，待官方提供 xunit.v3 兼容包后补自动化快照。
- **E2E**：首期不做自动 E2E；用手动验收清单覆盖主流程（见 `16-测试方案.md` §9）。

## 8. 设计系统集成

- **Theme**：`FluentTheme` + 自定义品牌色 Token；`App.axaml` 的 `ThemeDictionaries` 定义 Light / Dark 两套侧边栏、选中态、悬停态、内容面板、边框与文字画刷。
- **Icon**：Fluent System Icons（通过 `Projektanker.Icons.Avalonia` 加载）。
- **深色模式**：`GGD-0041` 以 `RequestedThemeVariant="Default"` 跟随操作系统主题；手动强制明 / 暗与 `AppState.ThemeMode` 持久化在 `GGD-0046` 落地。

## 9. 已废弃组件处理

- 废弃组件必须：标记 `[Obsolete]`，附迁移建议；在至少一个 MINOR 版本保留后再移除。
