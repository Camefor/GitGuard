# 云服务器生产部署手册（N/A）

> **本节声明**：GitGuard 是**本地单机工具**，无服务器部署场景。本文件在 GitGuard 项目中**不适用**。
>
> 保留本文件只为维持 ForgeAI 模板索引完整；若未来派生子项目（如团队协作服务端）需要生产部署流程，再基于本模板展开。

## 1. 为什么不适用

- GitGuard 的运行时位于**开发者本机**，由 Git 以 Hook 方式调起 CLI 可执行文件。
- 持久化只用本地 **SQLite 文件**；不涉及任何远程数据库、消息队列或 Web 服务。
- 没有「生产环境」概念；用户机器即是运行环境。
- 发行流程详见 [`14-部署文档.md`](./14-部署文档.md)（Native AOT 多平台构建 + 分发渠道）与 [`15-Docker部署.md`](./15-Docker部署.md)（仅 CI 构建）。

## 2. 若将来派生服务端子项目

如果未来出现「团队共享的规则下发服务 / 跨团队审计聚合服务」等需求，请：

1. 新建独立仓库或 `src/` 子项目：`GitGuard.Server`。
2. 将本文件作为模板**在该子项目中展开**，并链接到各自的 Runbook。
3. 本仓库主项目保留本声明不变，避免混淆。
