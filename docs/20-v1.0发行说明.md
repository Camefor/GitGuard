## 2. 版本亮点

### 2.1 检测规则库达到 60 条

- Secret 21 条：AWS、GitHub、GitLab、Slack、Stripe、npm、OpenAI、SendGrid、Hugging Face、Azure Storage、DigitalOcean、HashiCorp Vault、Postman、Shopify、PyPI、私钥、JWT、通用密码等。
- Privacy 14 条：中国大陆手机号 / 身份证 / 银行卡、邮箱、姓名与地址组合、护照、座机、SSN、IBAN、美国电话、英国 NINO、中国车牌、出生日期等。
- LocalPath 12 条：Unix 主目录、Windows 用户目录 / 盘符、UNC 共享、部署目录、macOS 挂载卷、Cygwin 与行内盘符路径等。
- Url 13 条：URL 内嵌凭据、查询参数令牌 / 密码、私有 IP / 内网域名、Slack / Discord / 飞书 Webhook、AWS / Google Cloud / Azure 签名 URL、数据库 URL 内嵌凭据、OAuth 刷新令牌等。
- 每条内置规则均包含正例、反例与边界夹具；声明式校验器覆盖 Shannon 熵、Luhn、身份证校验位与 IBAN 模 97。

### 2.2 提交 / 推送拦截闭环

- `gitguard install` / `uninstall` / `status` 管理 `pre-commit`、`pre-push` 与 `post-commit`，兼容 Husky / lefthook / pre-commit，不覆盖既有 Hook。
- 暂存区扫描严格基于 `git diff --cached`；推送扫描覆盖本次推送区间并携带来源 commit SHA。
- `--no-verify` 与 `GITGUARD_SKIP=1` 绕过事件写入 SQLite 审计，不伪装为正常通过。
- 扫描器异常默认 FailClosed，阻断 `commit` / `push`。

### 2.3 扫描、审计与误报治理

- `scan --all` 支持 HEAD 全量快照与历史扫描；`--max-files` 截断后可用 `--since` 续扫。
- 基线文件 `gitguard.baseline.v1` 排除历史已知噪声，后续全量扫描自动消费。
- `audit list` / `audit view` / `audit export` 提供分页查询、运行摘要与脱敏 JSON / CSV 导出。
- `allowlist` 按规则 / 路径 / 指纹管理白名单；配置文件 + SQLite 条目共同参与扫描策略。
- 自定义正则规则支持命名、严重度、上下文关键字与文件 glob；`gitguard rules list` / `view` 只读查看规则目录。
- 可选 Gitleaks 8.x 适配器按指纹去重并映射为 `GLK/SECRET/*`，可执行文件缺失时告警降级。
- URL 公共主机名白名单与 Markdown 围栏代码块感知降低文档类误报。

### 2.4 桌面端

- Avalonia 11.3 LTS 桌面端覆盖仓库管理、扫描历史与 Finding 明细、全局白名单、规则库、跨仓库日志与全局设置。
- 中 / 英即时切换、跟随系统明暗主题；审计数据与 CLI 共用本地 SQLite。
- Windows MSIX / macOS DMG / Linux AppImage 打包脚本与 `--smoke-test` 发行冒烟已落地。

### 2.5 发行形态

- CLI 采用 Native AOT 单文件发布，覆盖 `win-x64` / `linux-x64` / `osx-arm64` / `osx-x64`。
- 每个 CLI 产物附带 `SHA256SUMS`；桌面安装包作为独立构件上传。
- 输出支持中英文文本与 JSON，JSON 契约保持稳定。

## 4. 安装与升级

1. 从 Release 流水线构件下载对应平台的 `gitguard-<version>-<rid>.zip`，解压后校验 `SHA256SUMS`。
2. 将 `gitguard` / `gitguard.exe` 放到固定目录，在目标仓库执行一次 `gitguard install` 刷新 Hook 中固化的可执行文件路径。
3. 桌面端按平台安装：Windows MSIX（本基线默认未签名，开发者模式可侧载）、macOS DMG、Linux AppImage。
4. 升级不需要手动迁移数据库：SQLite Schema 迁移保持向后兼容，审计与白名单数据继续可用。

## 6. 已知限制

- macOS DMG / Linux AppImage 尚未在对应 runner 上完成首次发行冒烟。
- Windows MSIX 默认未签名；CLI Authenticode 签名与发行物 GPG 签名仍为 P2 规划。
- CI 常规流水线仅覆盖 Windows；macOS / Linux 构建与冒烟仅在 Release 工作流中执行。
- 运行环境需要 Git ≥ 2.9；GitGuard 不自带 Git。
- v1.0 的 3 个月稳定运行观察仍在进行中，期间发现的问题按 P0 / P1 优先级处理。
