## 2. 版本亮点

### 2.1 桌面端一键管理 Hook

- 仓库详情页右侧操作区新增「安装 Hook / 重新安装 Hook」与「卸载 Hook」。
- 安装按配置中的 `hooks` 子集执行；卸载始终覆盖 `pre-commit` / `pre-push` / `post-commit` 三类 GitGuard 托管 Hook，并还原 `<hook>.local.bak` 备份，未托管 Hook 不受影响。
- 目标 Hook 为二进制文件或符号链接时展示强制接管确认，确认后以 `--force` 语义备份并接管；卸载同样需要二次确认。
- 安装 / 卸载结果原地刷新仓库详情与按钮状态；错误按 `HookException` / `ConfigurationException` 映射为中 / 英本地化提示。

### 2.2 CLI 路径解析与持久化

- 桌面端按 `hooks.gitguard_executable_path` → PATH → 已知安装位置解析 GitGuard CLI，不回退桌面端 GUI 进程。
- 自动解析失败时弹出文件选择器；安装成功后路径写入 `desktop-settings.json` 的 `hookExecutablePath`，不写回项目 `.gitguard.yml` / `.gitconfig`。
- 后续安装通过 `GitGuardConfigOverrides` 注入该路径，重启桌面端后仍可复用。

### 2.3 Application 层共享 Hook 管理

- 新增 `HookManagementService` / `HookExecutableResolver` / `HookSelection`，统一 Hook 子集解析、可执行文件解析与安装 / 卸载调用。
- CLI `gitguard install` / `gitguard uninstall` 改为复用共享服务，既有命令参数、输出契约与退出码保持不变。
- 桌面端与 CLI 使用同一 `InstallHookUseCase` / `UninstallHookUseCase`，避免两端在备份、锁与强制接管语义上分叉。

### 2.4 桌面端运行稳定性

- `GitAccess` / `GitVersionProbe` 的 git 子进程统一以 `UseShellExecute=false` + `CreateNoWindow=true` 启动。
- Windows 桌面端（WinExe 宿主）在仓库列表 / 详情 / 扫描 / Hook 操作期间不再反复闪现控制台窗口。

### 2.5 桌面端主题对比度与操作区布局

- Light / Dark 主题补齐警告、危险、成功与状态徽标语义画刷；警告确认条、危险按钮与徽标文字在两种主题下均达到 WCAG AA 4.5:1，不再出现浅色按钮文字看不清的问题。
- 视图统一使用主题语义画刷，不再硬编码前景 / 背景 / 边框颜色；主题切换与跟随系统即时生效。
- 仓库详情操作区固定于详情底部，六个功能按钮使用换行布局；默认窗口调整为 1280×720 并居中，最小 1024×720 下按钮自动换行且完整可见。
- 新增主题资源与布局回归测试，防止后续改回硬编码颜色或单行裁切布局。

## 3. 升级说明

1. 版本号由 `1.0.0` 更新为 `1.1.0`，审计数据与 SQLite Schema 无需迁移。
2. `desktop-settings.json` 新增可选字段 `hookExecutablePath`；旧设置文件无需修改，缺失时继续自动探测。
3. CLI 命令与 JSON 契约不变；`gitguard install` / `uninstall` 的配置语义与退出码与 v1.0.0 一致。
4. 桌面端未内置 GitGuard CLI：使用 Hook 快捷管理前需确保系统 PATH 中存在 `gitguard` / `gitguard.exe`，或通过桌面端文件选择器指定可执行文件。

## 5. 已知限制

- 桌面端 Hook 操作依赖外部 GitGuard CLI，不包含 CLI 可执行文件本身；CLI 写入系统 PATH 的管理能力不在本版本范围。
- Windows MSIX / macOS DMG / Linux AppImage 的三平台发行冒烟沿用 v1.0 基线结果，v1.1 产物待下一次 Release 流水线验证。
